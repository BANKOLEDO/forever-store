# 🛒 Forever — Modern eCommerce Platform

Forever is a modern **eCommerce web application** built with React and Tailwind CSS.  
It delivers a **seamless, responsive, and scalable shopping experience**, showcasing my skills in frontend engineering, state management, and user-centric design.

🔗 **Live Demo** → [Forever](https://forever-store.vercel.app/)

---

## 🌟 Why Forever?
In a world where **user experience drives conversions**, Forever demonstrates how to combine:
- **Clean design** (minimal, responsive, mobile-first)
- **Intuitive interactions** (search, filters, categories)
- **Scalable architecture** (Context API for global state, reusable components)

This project is not just a store — it’s a **showcase of real-world eCommerce functionality**.

---

## 🚀 Core Features

- **Dynamic Home Page**
  - Hero banner with promotional content
  - Latest collections & best sellers
  - Store policies & newsletter signup  

- **Product Discovery**
  - Search with instant filtering  
  - Category browsing (Men, Women, Kids)  
  - Sub-categories (Topwear, Bottomwear, Winterwear)  

- **Shopping Experience**
  - Add to cart & cart management  
  - Checkout flow with pricing logic  
  - Responsive design (mobile, tablet, desktop)  

- **User Trust Elements**
  - Easy exchange & return policies  
  - Free shipping thresholds  

---

## 🛠 Tech Stack

- **Frontend:** React, Tailwind CSS  
- **State Management:** React Context API + Hooks  
- **Deployment:** Netlify
